01 · FEED

System of record vs derived timeline

Post/Follow 是事实；Feed table 是可重建派生状态。面试要说清 replay、lag、dedupe 和 stale user semantics。

02 · FAN-OUT

push/pull/hybrid 不是口号

大量 followees 伤 read，大量 followers 伤 write，celebrity 需要 read-time merge；hot post cache 要和 mutable aggregates 分开。

03 · REALTIME

Durable log + delivery channel

评论事实在 log/store；SSE/WebSocket 只是投递。Last-Event-ID、offset、replay 和 backpressure 定义恢复窗口。
