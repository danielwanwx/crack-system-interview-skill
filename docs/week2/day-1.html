今日验收

  • get 在返回前检查 expiry；过期 entry 绝不能因 janitor 尚未运行而继续可见。
  • LRU 的 hash map + doubly linked list 能让 lookup、touch、evict 都保持 O(1)。
  • 能明确回答：缓存里的值丢光后，从哪里恢复；若答不出，尚未定义 system of record。
必须产出：单节点状态图 + get/set/delete/expire/evict 时序 + 一张 SoR/derived 决策卡。
