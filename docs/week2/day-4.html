今日验收

  • 客户端上报 part 成功只用于进度；最终完成必须由服务端向 blob store 验证。
  • Complete 响应丢失时用同一 upload/file identity 查询状态或幂等完成，不能盲目新建第二对象。
  • 冲突解决以 server version 识别并发，保留用户数据；mtime 只能帮助展示，不能证明因果顺序。
必须产出：multipart state machine + upload commit/GC 表 + sync/conflict 时序 + signed URL security checklist。
