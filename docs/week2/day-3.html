今日验收

  • blob bytes 不穿过 application server；服务端只签发有限权限、有限时间、限定 object key 的 URL。
  • metadata.status=uploaded 之前，文件不能进入可见目录；orphan blob 与 orphan metadata 都有回收路径。
  • notification 只负责低延迟唤醒；丢通知后 cursor pull 仍能修复。
必须产出：Dropbox 控制面/数据面图 + metadata schema + upload/download/share/sync 四条时序。
